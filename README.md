# Live TV

[![License](https://img.shields.io/badge/License-MIT-blue)](./LICENSE "Go to license section")

單一 HTML 檔的台灣新聞直播頁，畫面來自各電視台的 YouTube 官方直播。<br>
直接開啟 https://rokaku.github.io/tv 即可使用。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| ↑ ↓ | 切台 |
| 數字 | 跳台 |
| Backspace | 上一台 |
| ← → | 音量 -10 / +10 |
| M | 靜音 |
| F | 全螢幕 |

## 解析度

播放器下方的「解析度」選單可選 自動 / 144P / 240P / 360P / 480P / 720P / 1080P，設定會記在瀏覽器裡。此設定只是向 YouTube 提出請求，實際畫質仍可能被調整。
